# Тренировки — PWA для персонального учёта силовых тренировок и калистеники

Современное веб-приложение (Progressive Web App) для ведения тренировочного дневника, отслеживания рабочих весов, таймера отдыха, баланса нагрузки по мышцам и прогресса силы. Написано на чистом HTML, CSS и JavaScript (ES Modules) без фреймворков и сборщиков — работает мгновенно, поддерживает офлайн-режим и устанавливается на iOS / Android как нативное приложение.

---

## Основные возможности

### 1. Мультиаккаунтность и онбординг
- **Личные профили по логину и PIN-коду**: каждый пользователь получает собственное изолированное пространство данных в облаке (` programs`, `sessions`, `exercises`, `meta`), при этом базовый каталог упражнений общий и пополняется для всех.
- **Пошаговый мастер регистрации (3 шага)**:
  1. Создание логина, PIN-кода и выбор языка интерфейса (**Русский / English**).
  2. Настройка параметров: собственный вес тела, единицы измерения (`кг` / `lb`), базовое время отдыха.
  3. Сборка первой программы тренировок из общей базы, выбор готового шаблона Fullbody или пропуск для свободного старта.
- **Быстрое переключение профилей**: сохранённые профили на устройстве переключаются в один тап, выход и смена аккаунта доступны прямо из карточки профиля в Настройках.

### 2. Главный экран и активная тренировка
- **Выпадающее меню выбора тренировки (Dropdown)**: компактный селектор со статистикой каждой программы (количество упражнений, сетов, дата последнего выполнения) и режимом **«Свободная тренировка»** (без шаблона).
- **Превью перед стартом**: интерактивный анатомический силуэт (вид спереди и сзади) показывает, какие мышечные группы и в каком объёме задействует выбранная программа, вместе с нумерованным списком упражнений.
- **Умное предзаполнение весов и повторов**:
  - Подставляет рабочие веса из последней тренировки по этой же программе (`прошлый раз: 62,5 кг × 9`).
  - Если в текущей программе упражнение ещё не выполнялось — подтягивает историю из других программ.
  - Подсказка под каждым подходом заполняется в один тап.
- **Подсказки прогрессии нагрузки**: если во всех рабочих подходах достигнута верхняя граница целевого диапазона повторов, карточка предлагает увеличить рабочий вес на шаг (`+2,5 кг` / `+5 lb`) одним нажатием.
- **Пауза тренировки**: кнопка **«Пауза / Продолжить»** в шапке активной тренировки приостанавливает как общий секундомер занятия (время паузы вычитается из итоговой длительности), так и активный таймер отдыха.
- **Плавное сворачивание выполненных упражнений**: когда все сеты упражнения закрыты, карточка плавно сворачивается в компактную строку со сводкой и галочкой (и так же плавно разворачивается обратно по нажатию).
- **Жесты и удобное управление сетами**:
  - **Свайп влево по подходу** с фоном-подложкой и иконкой корзины для быстрого удаления сета.
  - Переключение типа подхода **Рабочий ↔ Разминочный (`Р` / `W`)** нажатием на номер сета (разминочные сеты не запускают таймер отдыха и не искажают статистику).
  - Быстрая замена упражнения на аналогичное по целевой мышце, пропуск упражнения и перетаскивание (`Drag & Drop`) карточек прямо по ходу тренировки.
- **Упражнения со своим весом (`Bodyweight`)**: поддержка работы со своим весом (подтягивания, брусья, калистеника) и дополнительного отягощения — в тоннаж и расчётный максимум автоматически учитывается вес тела из профиля.

### 3. Таймер отдыха и тактильный отклик (Haptics)
- **Плавающий таймер отдыха** с круговым прогресс-рингом, быстрыми кнопками `−15с` / `+30с` и подсказкой следующего подхода.
- **Звуковой сигнал, вибрация и системные уведомления**: работают даже при сворачивании браузера; время рассчитывается по системным часам и не сбивается в фоне.
- **Многоуровневый тактильный отклик (`haptic`)**: различные паттерны отклика (`light`, `medium`, `heavy`, `success`, `warning`, `error`) при кликах по степперам, закрытии подходов, установке рекордов и свайпах (поддерживается как через Web Vibration API на Android, так и через нативный переключатель на iOS Safari 17.4+).

### 4. Итоги тренировки и карточка для шаринга (Share Card)
- По завершении тренировки (а также для любой прошлой тренировки в **Истории**) открывается сводка:
  - Общий объём (тоннаж), лучший расчётный максимум (`e1RM`), **Индекс нагрузки (`Load Index`)**, сравнение с прошлой тренировкой (`%`), длительность, анатомическая карта задействованных мышц и список новых личных рекордов (`PR`).
  - Если в ходе занятия вы изменили состав упражнений или число подходов, приложение предложит в один клик **обновить шаблон программы**.
- **Генератор PNG-карточки «Итог тренировки» (`<canvas>`)**:
  - Создаёт стильную картинку высокого разрешения (в тёмной или светлой теме) с именем профиля, датой, 4 главными метриками, силуэтом проработанных мышц, списком лучших подходов и бейджами `PR`.
  - Поддерживает отправку через системное меню «Поделиться» (`Web Share API`), копирование в буфер обмена и скачивание в PNG.

### 5. Программы и библиотека упражнений
- **Конструктор программ**: создание и редактирование программ тренировок (включая силовые сплиты, Fullbody и программы **Калистеники** со своим весом), настройка целевых повторов, отдыха и заметок, визуальное покрытие мышц на силуэте в реальном времени.
- **Библиотека упражнений по папкам мышечных групп**:
  - Все упражнения разбиты на аккуратные сворачиваемые карточки по мышечным группам со счётчиком и превью.
  - Поиск по названию и фильтрация по мышцам автоматически раскрывают нужные папки.
  - Современное меню создания/редактирования упражнения с быстрыми чипами выбора мышцы в один тап, сегментированным переключателем единиц (`кг | lb`), пресетами отдыха и тумблерами `Свой вес` / `RPE`.
  - По каждому упражнению в один клик доступна карточка с его личными рекордами и историей последних выполнений.

### 6. Аналитика и Прогресс
- **Общая сводка (Overview Dashboard)**: 4 главные плитки в верхней части экрана — всего тренировок (и за последние 30 дней), суммарный тоннаж (в кг/тоннах и средний за занятие), сумма рабочих сетов и повторов, общее число рекордов (`PR`) и средняя длительность тренировки.
- **Баланс по мышцам (`7 дн.` / `30 дн.` / `Все`)**: анатомическая карта спереди и сзади + плавно раскрывающаяся детальная разбивка рабочих подходов по каждой мышечной группе в процентах.
- **Индекс нагрузки (`Load Index`)**:
  - Интегральный показатель прогресса относительно базовой тренировки программы (принятой за `100` пунктов), учитывающий **Объём (55%)**, **Силу / e1RM (35%)** и **Плотность работы в минуту (10%)**.
  - Интерактивный SVG-график с плавной заливкой градиентом, линией скользящего среднего (тренд за 4 занятия) и вертикальным перекрестием при наведении/касании.
- **Сворачиваемые детальные разделы (Аккордеоны)**:
  - **Личные рекорды (`PR`)**: карточки всех рекордов по максимальному весу и расчётному одноповторному максимуму (формула Эпли) с датами.
  - **Прогресс по упражнению**: 3 графика по любому выбранному упражнению (рабочий вес, `e1RM`, объём).
  - **Собственный вес тела**: быстрый ввод текущего веса и график динамики массы тела.

### 7. История и управление данными
- **Календарная сетка активности за 12 недель (Heatmap)**: наглядная матрица тренировочных дней с быстрым переходом к занятиям выбранной даты.
- **Полное редактирование прошлых тренировок и шаринг**: любую тренировку из списка истории можно открыть, поделиться её карточкой итога, посмотреть сводку или отредактировать подходы/дату/длительность с автоматическим пересчётом всех метрик.
- **Экспорт и резервное копирование**:
  - Выгрузка всей истории тренировок в **CSV-таблицу** (с поддержкой кириллицы UTF-8 BOM для Excel и Google Sheets).
  - Создание полной резервной копии профиля в **JSON** и восстановление из файла.
- **Полная двуязычность (`RU` / `EN`)** и адаптивные темы оформления (**Тёмная / Светлая / Системная**).

## Хранение данных и синхронизация

Приложение использует **Firebase Realtime Database** в сочетании с мгновенным локальным кэшем (`localStorage`):
- Все данные приложения изолированы в ветке `fitnessApp/`:
  - `fitnessApp/users/{username}/exercises` — упражнения пользователя
  - `fitnessApp/users/{username}/programs` — программы тренировок
  - `fitnessApp/users/{username}/sessions` — история и активная тренировка
  - `fitnessApp/users/{username}/meta` — настройки профиля, профиль доступа и лог веса тела
  - `fitnessApp/sharedExercises` — общая библиотека упражнений, доступная всем профилям
- **Работа офлайн**: все изменения мгновенно сохраняются на устройстве и автоматически синхронизируются с облаком при появлении сети.

## Запуск и установка

### Локальный запуск
Так как проект использует нативные ES-модули без сборки, достаточно любого статического HTTP-сервера в корне папки:
```bash
python -m http.server 8000
```
После чего откройте `http://localhost:8000` в браузере.

### Деплой
- Репозиторий готов к автоматическому деплою на **Netlify** / **GitHub Pages** / **Vercel** без шага сборки (`publish = "."`).
- При выпуске обновлений версия кэша `CACHE_VERSION` в `sw.js` увеличивается, чтобы установленные на телефонах PWA автоматически обновили файлы оболочки.

### Установка на смартфон (PWA)
- **iOS (Safari)**: откройте сайт → нажмите **«Поделиться»** → **«На экран “Домой”»**.
- **Android (Chrome)**: откройте меню браузера `⋮` → **«Установить приложение»** (или «Добавить на главный экран»).
