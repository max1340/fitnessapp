# Тренировки — PWA для учёта силовых тренировок

Чистые HTML/CSS/JS (ES modules), без сборки. Данные — в Firestore с офлайн-кэшем. Интерфейс на русском, только ч/б палитра.

## Структура

```
index.html · styles.css · sw.js · manifest.webmanifest · firebase-config.js
firestore.rules · netlify.toml · tests.html (юнит-тесты метрик)
icons/            иконки (SVG + PNG, в т.ч. maskable и apple-touch)
js/app.js         роутер, оболочка, регистрация SW
js/db.js          Firestore (persistentLocalCache + multiple tabs)
js/store.js       состояние, CRUD, перенос веса, стартовые данные, экспорт/импорт
js/metrics.js     e1RM, объём, плотность, Load Index (веса в LI_WEIGHTS)
js/chart.js       SVG-графики; js/timer.js — таймер отдыха; js/ui.js — хелперы
js/views/*.js     workout, programs, exercises, progress, history, settings, entryCard
```

## 1. Настройка Firebase

Проект общий с другими вашими приложениями, поэтому **всё лежит в отдельной ветке Firestore `fitnessApp/{SPACE_ID}/…`**, а Firebase-приложение инициализируется под именем `fitness`. Realtime Database и чужие коллекции не затрагиваются.

1. **Проект.** Используйте существующий (`pc-building-b3d74`). Значения конфига уже в [firebase-config.js](firebase-config.js); для нового проекта: Console → ⚙ Project settings → General → Your apps → Web → Config.
2. **Firestore.** Console → Build → Firestore Database → Create database (если ещё нет; режим production, регион на ваш выбор). Это бесплатный тариф Spark; расход для личного использования — единицы тысяч операций в день.
3. **Auth.** Не используется (по ТЗ). Раздел Authentication включать не нужно.
4. **SPACE_ID.** В `firebase-config.js` замените `"main"` на длинную случайную строку. Без авторизации это единственная защита: кто знает `apiKey` и путь — может читать/писать. Не публикуйте репозиторий с этим значением.
5. **Rules.** Откройте Console → Firestore → Rules и **добавьте** блок `match /fitnessApp/<ваш SPACE_ID>/{collection}/{docId}` из [firestore.rules](firestore.rules) внутрь существующих правил (с тем же SPACE_ID). **Не заливайте файл целиком через `firebase deploy`** — он заменит правила других проектов.
6. **Домен.** Authentication для Firestore не нужен, поэтому «Authorized domains» трогать не обязательно. Если позже включите Auth — добавьте домен Netlify в Authentication → Settings → Authorized domains. Ограничения API key по HTTP-referrer (Google Cloud Console → Credentials) добавлять не рекомендуется без проверки: общий ключ используется и другими проектами.

## 2. Деплой на Netlify

- Через Drag & Drop: Netlify → Add new site → Deploy manually → перетащите папку проекта.
- Или из Git: build command пустой, publish directory `.` (уже в [netlify.toml](netlify.toml)).
- HTTPS нужен для service worker и Wake Lock — Netlify даёт его автоматически.
- При обновлении кода увеличивайте `CACHE_VERSION` в `sw.js`.

Локально: `python -m http.server 8000` и открыть `http://localhost:8000` (на localhost SW тоже работает).

## 3. Установка на телефон

- **iOS (Safari):** открыть сайт → «Поделиться» → «На экран “Домой”».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

Первый запуск — с сетью, чтобы закэшировались оболочка и модули Firebase. Затем в Настройках (⚙) нажмите **«Загрузить мою текущую программу»**.

## Как это работает

- **Офлайн.** Запись идёт в локальный кэш Firestore и уходит на сервер при появлении сети (индикатор «Офлайн / Синхр…» в шапке). Запросы к Firestore приложение не ждёт.
- **Активная тренировка** хранится в Firestore (`status: "active"`), сохраняется при каждом вводе (с debounce 350 мс и при сворачивании) и восстанавливается после закрытия.
- **Перенос веса:** считается по истории — последняя завершённая тренировка той же программы → «прошлый раз: 15 кг × 8»; иначе вес (без повторов) из любой другой программы → «из «…»: …»; иначе стартовые значения упражнения.
- **Load Index:** формула — в интерфейсе (иконка «?» на графике Прогресса). Веса — константа `LI_WEIGHTS` в `js/metrics.js`. Тесты: откройте `tests.html` (20 проверок).

## Решения, не описанные в ТЗ

- Авторизации нет, поэтому «Выход из аккаунта» в настройках отсутствует.
- Настройки (кроме темы-кэша) синхронизируются документом `meta/settings`.
- Экспорт/импорт — JSON; импорт добавляет/перезаписывает записи по id, ничего не удаляет.
- Baseline = первая завершённая тренировка программы; сброс — выбором тренировки из списка. Более ранние тренировки скрываются с графика, но не удаляются.
- Изменение индекса за 4/12 недель — разница с последней тренировкой, которая была не позже N недель назад (если таких нет — с первой точкой ряда).
- Сравнение с прошлой тренировкой в сводке — изменение объёма (%) по общим упражнениям.
- Разминочные сеты не запускают таймер отдыха. Невыполненные сеты при завершении сохраняются, но в метрики не входят.
- Длительность тренировки = время от старта до «Завершить» (правится в Истории). Пауза не учитывается.
- Выполнить сет без повторов нельзя (фокус уходит в поле повторов); вес может быть пустым (собственный вес).
- Упражнение, которое уже есть в истории, нельзя удалить — только архивировать.
- «Свободная тренировка» (без программы) — дополнительная кнопка; в «Прогресс» она не попадает.
- Пункт 5 стартовой программы («20–25 кг»): стартовый вес 20 кг, диапазон — в заметке.
- Для Lighthouse-проверок установите сайт по HTTPS (Netlify).

## Ограничения

- Без авторизации данные защищены только секретным `SPACE_ID`; для реальной приватности подключите Firebase Auth (Anonymous/Google) и ограничьте rules по `request.auth.uid`.
- Если два устройства одновременно правят одну активную тренировку, побеждает последняя запись документа (экран активной тренировки не перерисовывается чужими правками).
- Wake Lock не поддерживается в старых браузерах/iOS < 16.4 — тогда экран может гаснуть.
- Вибрация не работает в iOS Safari; звук таймера на iOS включается только после первого тапа в приложении.
- Таймер отдыха работает, пока приложение открыто; в фоне iOS может приостановить вкладку (при возврате таймер показывает реальное оставшееся время).
- Режим приватного просмотра может отключить офлайн-кэш Firestore (приложение переходит в онлайн-режим).
- Drag & drop порядка в программах — через ручку ⋮⋮; запасные кнопки «вверх/вниз» рядом.
